A simple app to demonstrate CI/CD with GitHub Actions & Netlify

About This Tomato

  • GitHub: Code repository and version control
  • GitHub Actions: Automated testing on every push
  • Jest: Unit tests with code coverage reporting
  • Netlify: Automatic deployment of this webpage

Test Coverage Examples

This project includes Jest tests for all calculator functions:

  • ✓ Subtraction with various inputs
  • ✓ Multiplication including zero cases
  • ✓ Division with error handling for division by zero
  • X Showing the total
